# Instructions

Project Structure --> https://amadeus.atlassian.net/wiki/spaces/CATS/pages/2509655836/GENIe+Project+Structure

This repo contains the code to work with ChatGPT4o instances from Azure.

The UI is created using streamlit.

A vector database is created using llama-index

# User Guide:

Please refer the user guide to run GENIe : https://amadeus.atlassian.net/wiki/x/WoI0n

# Below are the instructions you need to setup your local environment:

* install python 3.12.2 - from https://www.python.org/downloads/

* Create your fork of the repo https://github.com/amadeus-res/content-transformer-new , master branch.

* clone your forked repo ( git clone https://github.com/<<user...>>/content-transformer-new --recurse-submodules)

*(Microsoft Visual C++ 14.0 or greater is required. Get it with "Microsoft C++ Build Tools": https://visualstudio.microsoft.com/visual-cpp-build-tools/ . Install Desktop developement with C++)*

# Execution 

## For XSLT Manager:
Run `streamlit run app/xslt_manager/xslt_manager.py`
